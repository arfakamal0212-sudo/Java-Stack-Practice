# Java Stack Practice

This repository contains Java Stack programs using arrays and user input, covering basic stack operations and beginner-friendly DSA practice.

## Programs Included

### Basic Stack Operations
- Push
- Pop
- Peek
- Display Stack

### Stack Applications
- Parentheses Check
- Reverse String Using Stack
- Menu-Driven Stack Program

## Concepts Covered

- Stack
- LIFO (Last In, First Out)
- Push Operation
- Pop Operation
- Peek Operation
- Stack Traversal
- Stack Overflow
- Stack Underflow
- Parentheses Validation
- String Reversal Using Stack
- Menu-Driven Programming

Java
